# Affordia Health

Production website for [affordiahealth.com](https://affordiahealth.com/).

## Repository structure

- `docs/` — complete static website published by GitHub Pages
- `CNAME` — custom-domain record kept at the repository root
- `A` — DNS reference records for the apex domain and `www`

GitHub Pages publishes the `docs/` directory from the `main1` branch. The generated website includes the main marketing pages, consultation page, and the complete information library.
